# Research Section for thegoodneighborguard.com

These files contain a complete research section component for your main website.

## Files included:
- `research-section.html` - Complete HTML structure with example integration
- `research-section.css` - All styling and animations
- `research-section.js` - JavaScript for dropdown and tab functionality

## Integration Instructions:

### 1. Add to your website header navigation:
```html
<a href="#research-section" class="nav-link">Research</a>
```

### 2. Add the research section to your page:
Copy the entire `<section id="research-section" class="research-section">` block from the HTML file and paste it where you want the research section to appear on your website.

### 3. Include the CSS:
Either:
- Link to the CSS file: `<link rel="stylesheet" href="research-section.css">`
- Or copy the CSS content into your existing stylesheet

### 4. Include the JavaScript:
Either:
- Link to the JS file: `<script src="research-section.js"></script>`
- Or copy the JavaScript content into your existing JS file
